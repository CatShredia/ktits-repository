# OAIP Repository

Этот репозиторий содержит код, написанный в рамках учебного курса по программированию на языке C#. 
Проект включает в себя различные практические задания, примеры работы с файлами, коллекциями, 
объектно-ориентированным программированием (ООП), а также работу с PDF и Word документами.

## Структура репозитория

- **OAIP/**: Основная директория проекта.
  - **0.10.18/**: Практика от 18.10.2025. Работа с массивами, сортировка, реверс и очистка.
  - **0.11.21/**: Практика от 21.11.2025. Симуляция исследовательской миссии и менеджер кафе.
  - **0.11.28/**: Практика от 28.11.2025. Работа с коллекциями: удаление нечетных чисел, умножение на индекс, поиск повторяющихся элементов.
  - **0.12.09/**: Практика от 09.12.2025. Работа с символами и строками.
  - **01.14/**: Практика от 14.01.2025. Обработка исключений.
  - **01.21.files/**: Практика от 21.01.2025. Работа с файлами: создание, чтение, запись.
  - **01.24.files/**: Практика от 24.01.2025. Продолжение работы с файлами: подсчет строк, слов, символов.
  - **01.28.pdf/**: Практика от 28.01.2025. Создание PDF-документов.
  - **01.31.docx/**: Практика от 31.01.2025. Работа с Word-документами (NPOI и Xceed.Words.NET).
  - **02.07.collections/**: Практика от 07.02.2025. Работа с коллекциями: словари, стеки, списки.
  - **02.14.OOP/**: Практика от 14.02.2025. Основы объектно-ориентированного программирования.
  - **02.18.fynas/**: Практика от 18.02.2025. Финансовый менеджер: учет доходов и расходов.
  - **OAIP-system/**: Вспомогательные классы для работы с массивами, файлами и строками.
  - **Caesar.cs**: Реализация шифра Цезаря.
  - **OAIP.csproj**: Файл проекта C#.
  - **OAIP.sln**: Файл решения Visual Studio.
  - **Program.cs**: Основной файл программы с меню для выбора практик.

## Используемые технологии и библиотеки

- **C#**: Основной язык программирования.
- **NPOI**: Библиотека для работы с Word и Excel документами.
- **PDFsharp**: Библиотека для создания PDF-документов.
- **Xceed.Words.NET**: Библиотека для работы с Word документами.

## Как использовать

1. Убедитесь, что у вас установлена среда разработки, поддерживающая .NET (например, Visual Studio| Visual Studio Code).
2. Клонируйте репозиторий:
3. Откройте файл `OAIP.sln` в Visual Studio.
4. Запустите проект. В консоли появится меню для выбора практики.
5. Выберите нужную практику, введя соответствующую дату или название.

## Примечания

- Некоторые функции могут требовать установки дополнительных библиотек (например, NPOI, PDFsharp, Xceed.Words.NET).
- В коде используются комментарии для пояснения работы методов и функций.
- Для работы с Word документами через Xceed.Words.NET требуется лицензионный ключ.
