# CinemaProject - Веб-приложение каталога фильмов

Полнофункциональное веб-приложение для управления и просмотра каталога фильмов с аутентификацией пользователей, системой рейтингов и разграничением доступа по ролям.

## Обзор

CinemaProject — это комплексная система каталога фильмов, которая позволяет пользователям просматривать фильмы, оценивать их и управлять коллекциями. Администраторы имеют полный контроль над каталогом, включая фильмы, жанры, пользователей и рейтинги.

Приложение демонстрирует современные практики разработки .NET:
- RESTful API архитектура
- JWT-аутентификация
- Авторизация на основе ролей
- Чистое разделение ответственности
- Адаптивный фронтенд на Blazor WebAssembly

## Возможности

### Публичные функции
- **Каталог фильмов** — Просмотр всех фильмов с обложками, описаниями и рейтингами
- **Поиск и фильтрация** — Поиск фильмов по названию, фильтрация по жанру
- **Сортировка** — Сортировка по названию, дате выхода или рейтингу (по возрастанию/убыванию)
- **Детали фильма** — Подробная информация включая средний рейтинг и количество оценок
- **Список жанров** — Просмотр доступных жанров фильмов

### Функции для зарегистрированных пользователей
- **Регистрация** — Создание аккаунта с автоматическим назначением роли "client"
- **Аутентификация** — Безопасный вход с JWT-токенами (срок действия 7 дней)
- **Управление профилем** — Просмотр и редактирование личной информации
- **Оценка фильмов** — Выставление рейтингов (шкала 1-10) для любого фильма
- **Управление своими оценками** — Изменение и удаление собственных рейтингов
- **Одна оценка на фильм** — Каждый пользователь может оценить фильм один раз

### Функции администратора
- **Управление фильмами**
  - Создание новых фильмов с названием, описанием, датой выхода, жанром
  - Загрузка постеров фильмов (JPEG, PNG, WebP, GIF; макс. 5МБ)
  - Поддержка внешних URL изображений
  - Редактирование и удаление фильмов
  - Просмотр "Мои фильмы" — фильмы, созданные администратором

- **Управление жанрами**
  - Создание, редактирование и удаление жанров фильмов
  - Управление каталогом жанров

- **Управление пользователями**
  - Просмотр всех пользователей с поиском и фильтрацией
  - Создание новых пользователей с назначением роли
  - Редактирование профилей и учётных данных пользователей
  - Удаление пользователей и их данных для входа
  - Фильтрация пользователей по роли

- **Управление рейтингами**
  - Просмотр всех рейтингов в системе
  - Обновление или удаление любого пользовательского рейтинга

## Схема базы данных

### Диаграмма связей сущностей

```
┌─────────────┐       ┌─────────────┐
│   Roles     │       │   Genres    │
├─────────────┤       ├─────────────┤
│ Id          │       │ Id          │
│ Name        │       │ Name        │
└──────┬──────┘       └──────┬──────┘
       │                     │
       │ 1:N                 │ 1:N
       ▼                     ▼
┌─────────────┐       ┌─────────────┐
│   Users     │       │   Films     │
├─────────────┤       ├─────────────┤
│ Id          │◄──────│ Id          │
│ Surname     │       │ Name        │
│ Name        │       │ Description │
│ Email       │       │ ReleaseDate │
│ Gender      │       │ ImageUrl    │
│ Description │       │ GenreId     │
│ RoleId      │──────►│ AuthorId    │
└──────┬──────┘       └──────┬──────┘
       │                     │
       │ 1:1                 │ 1:N
       ▼                     ▼
┌─────────────┐       ┌─────────────┐
│   Logins    │       │  Ratings    │
├─────────────┤       ├─────────────┤
│ Id          │       │ Id          │
│ LoginValue  │       │ Value       │
│ PasswordHash│       │ FilmId      │
│ UserId      │──────►│ AuthorId    │
└─────────────┘       └─────────────┘
```

### Описание таблиц

| Таблица | Колонки | Описание |
|---------|---------|----------|
| **Roles** | Id, Name | Роли пользователей (admin, client) |
| **Users** | Id, Surname, Name, Email, Gender, Description, RoleId | Профили пользователей |
| **Logins** | Id, LoginValue, PasswordHash, UserId | Учётные данные аутентификации (1:1 с Users) |
| **Genres** | Id, Name | Жанры фильмов |
| **Films** | Id, Name, Description, ReleaseDate, ImageUrl, GenreId, AuthorId | Каталог фильмов |
| **Ratings** | Id, Value (1-10), FilmId, AuthorId | Пользовательские рейтинги фильмов |

### Связи

- **Users → Roles**: Многие-к-одному (SET NULL при удалении)
- **Users → Logins**: Один-к-одному (CASCADE при удалении)
- **Users → Films**: Один-ко-многим (SET NULL при удалении)
- **Users → Ratings**: Один-ко-многим (SET NULL при удалении)
- **Genres → Films**: Один-ко-многим (SET NULL при удалении)
- **Films → Ratings**: Один-ко-многим (CASCADE при удалении)

## Установка и настройка

### Требования

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [PostgreSQL 15+](https://www.postgresql.org/download/)
- [Git](https://git-scm.com/downloads)

### Шаг 1: Клонирование репозитория

```bash
git clone <repository-url>
cd CinemaProject
```

### Шаг 2: Настройка базы данных

1. **Создание базы данных PostgreSQL**

```sql
CREATE DATABASE "cinemaDB";
```

2. **Выполнение схемы и тестовых данных**

Выполните файл `insert_sql.sql`:

```bash
psql -U postgres -d cinemaDB -f insert_sql.sql
```

Или используйте pgAdmin/другой PostgreSQL клиент для выполнения SQL файла.

### Шаг 3: Настройка API

Отредактируйте `CinemaAPI/appsettings.json`:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=cinemaDB;Username=postgres;Password=your_password"
  },
  "JwtSettings": {
    "Issuer": "CinemaAPI",
    "Audience": "CinemaAPIUsers",
    "Key": "your_secret_key_at_least_32_chars"
  }
}
```

### Шаг 4: Сборка и запуск

**Backend (CinemaAPI):**

```bash
cd CinemaAPI
dotnet restore
dotnet run
```

API запустится на `https://localhost:7156` и `http://localhost:5000`

**Frontend (CinemaBlazor):**

Откройте новый терминал:

```bash
cd CinemaBlazor
dotnet restore
dotnet run
```

Blazor приложение запустится на `https://localhost:7157`

### Шаг 5: Доступ к приложению

Откройте браузер и перейдите на:
- **Фронтенд:** `https://localhost:7157`
- **API Swagger:** `https://localhost:7156/swagger`

## Справочник API

### Базовый URL
```
https://localhost:7156/api
```

### Endpoints аутентификации

| Метод | Endpoint | Описание | Требуется аутентификация |
|--------|----------|----------|-------------------------|
| POST | `/Auth/register` | Регистрация нового пользователя | Нет |
| POST | `/Auth/login` | Вход и получение JWT токена | Нет |
| GET | `/Auth/me` | Получить профиль текущего пользователя | Да |
| PUT | `/Auth/me` | Обновить профиль текущего пользователя | Да |

### Endpoints фильмов

| Метод | Endpoint | Описание | Требуется аутентификация | Роль |
|--------|----------|----------|-------------------------|------|
| GET | `/Films` | Получить все фильмы (с поиском, фильтрацией, сортировкой) | Нет | - |
| GET | `/Films/{id}` | Получить фильм по ID | Нет | - |
| POST | `/Films` | Создать новый фильм | Да | Admin |
| PUT | `/Films/{id}` | Обновить фильм | Да | Admin |
| DELETE | `/Films/{id}` | Удалить фильм | Да | Admin |
| GET | `/Films/my-films` | Получить фильмы текущего автора | Да | Admin |

**Параметры запроса для GET /Films:**
- `search` — Поиск по названию фильма
- `genreId` — Фильтр по жанру
- `sortBy` — Поле сортировки (name, releaseDate, rating)
- `isAscending` — Направление сортировки

### Endpoints жанров

| Метод | Endpoint | Описание | Требуется аутентификация | Роль |
|--------|----------|----------|-------------------------|------|
| GET | `/Genres` | Получить все жанры | Нет | - |
| GET | `/Genres/{id}` | Получить жанр по ID | Нет | - |
| POST | `/Genres` | Создать новый жанр | Да | Admin |
| PUT | `/Genres/{id}` | Обновить жанр | Да | Admin |
| DELETE | `/Genres/{id}` | Удалить жанр | Да | Admin |

### Endpoints рейтингов

| Метод | Endpoint | Описание | Требуется аутентификация | Роль |
|--------|----------|----------|-------------------------|------|
| GET | `/Ratings` | Получить все рейтинги | Да | Admin, Client |
| GET | `/Ratings/{id}` | Получить рейтинг по ID | Да | Admin, Client |
| POST | `/Ratings` | Создать новый рейтинг | Да | Admin, Client |
| PUT | `/Ratings/{id}` | Обновить рейтинг | Да | Admin или владелец |
| DELETE | `/Ratings/{id}` | Удалить рейтинг | Да | Admin или владелец |
| GET | `/Ratings/film/{filmId}/my-rating` | Получить рейтинг текущего пользователя для фильма | Да | Admin, Client |

**Примечание:** Пользователи могут изменять и удалять только свои собственные рейтинги. Администраторы могут управлять любыми рейтингами.

## Роли пользователей

### Client (по умолчанию)

**Разрешения:**
- Просмотр фильмов и жанров
- Поиск и фильтрация фильмов
- Оценка фильмов (1-10)
- **Изменение своих оценок**
- **Удаление своих оценок**
- Просмотр и редактирование собственного профиля
- Просмотр собственных рейтингов

**Ограничения:**
- Нельзя создавать/редактировать/удалять фильмы
- Нельзя управлять жанрами
- Нельзя управлять другими пользователями
- Нельзя удалять чужие рейтинги

### Admin

**Разрешения:**
- Все разрешения Client
- Создание, редактирование, удаление фильмов
- Загрузка изображений фильмов
- Создание, редактирование, удаление жанров
- Создание, редактирование, удаление пользователей
- Управление учётными данными пользователей
- Обновление/удаление любого рейтинга
- Просмотр "Мои фильмы" (созданные фильмы)

## Устранение неполадок

### Распространённые проблемы

**1. Ошибка подключения к базе данных**

```
Error: Connection refused
```

**Решение:** Убедитесь, что PostgreSQL запущен и строка подключения верна.

```bash
# Проверка статуса PostgreSQL
pg_ctl status

# Перезапуск PostgreSQL
pg_ctl restart
```

**2. Недействительный JWT токен**

```
Error: Invalid token
```

**Решение:** Проверьте, что JWT ключ в appsettings.json совпадает между фронтендом и бэкендом.

**3. CORS ошибка**

```
Error: Access to fetch has been blocked by CORS policy
```

**Решение:** Добавьте URL фронтенда в `CorsOrigins` в appsettings.json.

**4. Ошибка загрузки изображения**

```
Error: File too large or invalid format
```

**Решение:** Проверьте `ImageSettings` в appsettings.json на предмет ограничений размера и разрешённых расширений.

**5. Порт уже используется**

```
Error: Failed to bind to address https://localhost:7156
```

**Решение:** Измените порт в `launchSettings.json` или остановите конфликтующий процесс.

```bash
# Найти процесс на порту 7156 (Windows)
netstat -ano | findstr :7156

# Завершить процесс
taskkill /PID <PID> /F
```

**6. Пользователь не может изменить свою оценку**

```
Error: 403 Forbidden
```

**Решение:** Убедитесь, что пользователь является владельцем рейтинга. Проверка авторства выполняется по `AuthorId` в базе данных.
