# Skin Sprites

Положите сюда PNG-спрайты для скинов.

## Структура
- `Platform/` — спрайты для платформы
- `Ball/` — спрайты для мяча

## Как добавить скин
1. Поместите PNG-файл в соответствующую папку
2. В Unity перетащите спрайт на элемент массива `skinSprites` в компоненте `SkinManager` на сцене
3. Укажите `spriteName` — имя, совпадающее с полем `Name` скина из БД (или `PrefabPath`)
