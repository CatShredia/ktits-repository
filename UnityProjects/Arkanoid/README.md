# 🕹️ Arkanoid

Классическая игра **Arkanoid** на Unity, где игрок управляет платформой, отбивает мяч и разрушает блоки.

## 📖 Описание

Игрок управляет платформой внизу экрана, которая должна отбивать мяч. Мяч отскакивает от платформы и разрушает блоки в верхней части экрана. Цель — очистить все разрушаемые блоки и перейти на следующий уровень.

---

## 🎮 Управление

| Действие | Клавиатура | Мобильное устройство |
|----------|------------|---------------------|
| Движение влево | `A` | Касание левой части экрана |
| Движение вправо | `D` | Касание правой части экрана |
| Запуск мяча | `Пробел` | — |
| Пауза | `Esc` | — |
| Выход из игры | `Esc` (в меню) | — |

## 🎯 Особенности игры

### Уровни
- **3 основных уровня** с возрастающей сложностью
- **Видео-фоны** для каждого уровня
- Автоматическая загрузка следующего уровня после очистки всех блоков

### Жизни
- У игрока есть **3 жизни** (сердца)
- При падении мяча вниз — теряется жизнь
- При потере всех жизней — экран проигрыша

### Блоки
| Тип блока | Описание |
|-----------|----------|
| 🟫 Обычный | Разрушается с одного удара |
| 🟥 Красный | При разрушении добавляет жизнь (+1 ❤️) |
| 🟦 Синий | При разрушении создаёт дополнительный мяч |
| ⬜ Неразрушимый | Не разрушается, мяч отскакивает |
| 🟪 Многопрочный | Имеет 2–4 HP, становится прозрачнее при повреждении |

### Бонусы
Выпадают из блоков с вероятностью **20%**:

| Бонус | Эффект | Длительность |
|-------|--------|--------------|
| ⚡ Ускорение мяча | Увеличивает скорость мяча | 10 сек |
| 🐌 Замедление мяча | Уменьшает скорость мяча | 10 сек |
| 📏 Увеличение платформы | Платформа становится шире | 10 сек |
| 📐 Уменьшение платформы | Платформа становится уже | 10 сек |
| 🔮 Клон мяча | Создаёт дополнительный мяч | Мгновенно |

## 🚀 Запуск игры

1. Откройте проект в **Unity 6000.x** (или совместимой версии)
2. Откройте сцену `Assets/Scenes/MainScene.unity`
3. Нажмите **Play** в редакторе Unity

### Сборка
1. `File → Build Settings`
2. Выберите платформу (Windows, Android, и т.д.)
3. Нажмите **Build**

## 📌 Примечания

- Неразрушимые блоки нельзя уничтожить — мяч только отскакивает от них
- Многопрочные блоки меняют прозрачность в зависимости от оставшегося HP
- При одновременном действии противоположных бонусов (ускорение/замедление) они отменяют друг друга
- Клонированные мячи исчезают при падении вниз, основной мяч вызывает потерю жизни
