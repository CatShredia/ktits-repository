# Результаты тестирования

Дата проверки: 07.10.2026.

Сценарии раздела 8 технического задания выполнены через сервисы, которые вызывают экраны приложения. Созданные для проверки клиенты, автомобили, запись, заказ-наряд, счёт и платежи удалены. Начальные данные сохранены: в периоде 01.09.2026–31.12.2026 один заказ и выручка 5400,00 ₽.

## Списки

На экранах клиентов, автомобилей, услуг, запчастей, записей и заказ-нарядов поиск и фильтр задаются вместе и применяются одним запросом. Пустой результат показывает пустой список.

Проверено:

- клиенты ищутся по выбранному полю и сортируются по алфавиту, страницы по 10 и по 20 записей;
- автомобили ищутся по VIN и госномеру и сортируются по пробегу;
- услуги ищутся по названию и одновременно ограничиваются ценой и продолжительностью, список идёт по возрастанию стоимости;
- запчасти отбираются по поставщику и остатку ниже минимума;
- записи отбираются по клиенту, статусу, механику и дате; если указано время, остаётся эта минута;
- заказ-наряды отбираются по клиенту или госномеру вместе со статусом, механиком и датой создания, новые заказы выше.

При 16 клиентах страница размером 10 показала 10 записей, следующая — оставшиеся 6. Страница размером 20 показала 16, то есть не больше выбранного размера.

## Сценарии

| Сценарий | Ожидание | Фактический результат |
|---|---|---|
| Вход с неверным паролем | Сообщение об ошибке, главное окно роли не открывается | Ошибка «Неверный логин или пароль.», пользователь не возвращён. Верные пароли открывают роли администратора, механика и руководителя |
| Новый клиент и два его автомобиля | Оба автомобиля находятся поиском по государственному номеру и по VIN | Клиент сохранён. По госномеру найден один автомобиль, по VIN — второй. Чужое поле даёт пустой список без ошибки |
| Запись на услугу механику, не связанному с услугой | Запись не сохраняется, текст ошибки виден пользователю | Сохранение отклонено: «Механик не выполняет выбранную услугу.» |
| Заказ-наряд, осмотр, услуга, запчасть в пределах остатка | Статус меняется, остаток уменьшен на количество в заказе | Осмотр и услуга сохранены, статус «Диагностика», остаток фильтра 12 → 11 |
| Запчасть сверх остатка | Строка не создаётся, остаток прежний | Отказ: «На складе 11 шт., запрошено 12. Запчасть не добавлена.». Остаток остался 11 |

| Список клиентов длиннее размера страницы | Видна запрошенная страница, а не все записи сразу | Всего 16. Страница 1 по 10 показывает 10, страница 2 — 6, страница по 20 — 16. Пустой поиск даёт пустой список |
