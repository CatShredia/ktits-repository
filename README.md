# Minesweeper (Сапёр)

Игра «Сапёр» с многослойной архитектурой, консольным и графическим (Avalonia UI) интерфейсами, единой SQLite-базой данных.

## 🏗 Архитектура

```
Minesweeper.sln
├── Minesweeper.Core         # Бизнес-логика (без UI и БД)
├── Minesweeper.Data         # EF Core, SQLite, репозитории
├── Minesweeper.ConsoleApp   # Консольный клиент
└── Minesweeper.AvaloniaApp  # Графический клиент (MVVM)
```

## ⚙️ Требования

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Avalonia UI (кроссплатформенно: Windows / Linux / macOS)

## 🚀 Установка и запуск

```bash
git clone https://github.com/CatShredia/ktits-repository.git
cd ktits-repository
git checkout sapper
dotnet restore
```

База данных `minesweeper.db` создаётся автоматически при первом запуске.

## 🖥 Console App

### Запуск
```bash
dotnet run --project Minesweeper.ConsoleApp
```

### Управление
| Действие | Команда |
|---|---|
| Открыть ячейку | `open X Y` (например, `open 3 4`) |
| Поставить/снять флаг | `flag X Y` |
| Координаты | `X` — столбец, `Y` — строка (от 0) |

### Обозначения на поле
- `.` — закрытая ячейка
- `F` — флаг
- `*` — мина
- `0–8` — количество мин вокруг

### Главное меню
1. **Новая игра** — выбор сложности (1/2/3)
2. **История игр** — список ваших партий с просмотром карты мин
3. **Таблица лидеров** — Топ-10 побед по сложности с просмотром карты мин лидера
4. **Выйти**

## 🎨 Avalonia App

### Запуск
```bash
dotnet run --project Minesweeper.AvaloniaApp
```

### Управление
| Действие | Клавиша |
|---|---|
| Открыть ячейку | **ЛКМ** |
| Поставить/снять флаг | **ПКМ** |

### Экраны
- **Login** — вход / регистрация (BCrypt-хеширование паролей)
- **Menu** — выбор сложности:
  - Beginner (9×9, 10 мин)
  - Amateur (12×12, 20 мин)
  - Professional (20×20, 40 мин)
- **Game** — поле, динамический таймер, кнопка «Back»
- **History / Leaderboard** — просмотр карт мин

### Цвета цифр (классический Сапёр)
- **1** — синий, **2** — зелёный, **3** — красный

## 🎮 Игровой процесс

1. **Безопасный первый клик** — мины генерируются после первого хода; первая ячейка и её соседи всегда безопасны.
2. **Каскадное открытие** — пустые ячейки раскрываются автоматически (BFS).
3. **Таймер** — стартует с первого хода, останавливается при победе/поражении.
4. **Завершение**:
   - 🎉 **Победа** — открыты все безопасные ячейки
   - 💥 **Поражение** — взорвана мина (поле раскрывается)

## 🗄 База данных

- **Тип:** SQLite
- **Файл:** `bin/Debug/net8.0/minesweeper.db` (создаётся автоматически)
- **Сущности:**
  - `User` — Id, Login, PasswordHash
  - `Game` — Id, UserId, Size, Status, TimeInSeconds, Date, MineMap (JSON)
- **Пароли:** хэшируются через BCrypt
- **Индексы:** по `(Size, Status, TimeInSeconds)` для быстрого лидерборда
